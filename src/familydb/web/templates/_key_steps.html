{# How to get a key from each company, for setup's model step and the AI model settings page. #} {% if company == 'openai' %}

  1. Open OpenAI’s developer platform and sign in, or make an account. It is separate from a ChatGPT subscription, which does not include this.

  2. Add some credit under Billing: add a card, then buy a small amount such as $5 or $10.

  3. Set a monthly budget under Limits, so it can never cost more than you expect.

  4. Open API keys, press Create new secret key, name it {{ site_title }}, and copy it. It starts with sk- and is shown only once, so paste it below straight away.

{% elif company == 'anthropic' %}

  1. Open the Claude Console and sign in, or make an account. It is separate from a Claude.ai subscription, which does not include this.

  2. Add credit under Billing: $5 or $10 is plenty to start.

  3. Set a spend limit under Limits.

  4. Open API keys, press Create key, name it {{ site_title }}, and copy it. It starts with sk-ant-.

{% else %}

  1. Open Google AI Studio’s API keys and sign in with a Google account.

  2. Press Create API key, choosing or making a project if it asks, and copy the key. It starts with AIza.

  3. Turn on billing for that project; AI Studio offers it beside the key. Without it, Google gives only a small free allowance and may use what is sent to it to improve its products, which you may not want for a family’s messages.

{% endif %}

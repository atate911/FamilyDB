  1. Get the name. Any registrar sells one, usually for $10 to $20 a year, or use a part of one you already have, such as family.yourname.com.
  2. Point it here. Where the name was bought, add an A record for {{ name }} pointing at {% if served.reached_by == 'public' %}{{ served.host }}, this server's address. {% elif served.reached_by == 'private' %}this network's address on the internet (your router's; {{ served.host }} is only this server's address at home), and have the router pass ports 80 and 443 on to this server. {% else %}this server's address on the internet, the one your provider shows.{% endif %}
  3. Wait for it to take. On the server, dig +short {{ name }} prints that address once it has: usually minutes, sometimes an hour.
  4. Switch to it. On the server, as whoever looks after it: 
    sudo {{ served.script }} https {{ name }}
    That gets the certificate and restarts FamilyDB to match. The page is then at https://{{ name }}/, and the old address finds nothing, so open the new one and keep it on phones' home screens again.
    Installed with Docker

WEB_TRUST_PROXY=true
COMPOSE_PROFILES=tls

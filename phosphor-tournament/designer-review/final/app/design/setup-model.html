Step 3 of 7 · about 5 minutes · needed before it can answer

Connect an AI model

FamilyDB uses an AI model to understand what the family says and to write its answers. It needs an account with one of these three companies, and you pay the company for what it uses: for a family, usually a few dollars a month. As well as any limit you set with the company, FamilyDB stops for the day once it has spent its own daily limit (US$1.00).

OpenAIrecommendedThe least expensive by far for what FamilyDB does, so it is the one it starts with.AnthropicClaude. Several times dearer a message with the model it starts on.GoogleGemini, from Google. In between on price.

Get a key from OpenAI

  1. Open OpenAI’s developer platform and sign in, or make an account. It is separate from a ChatGPT subscription, which does not include this.

  2. Add some credit under Billing: add a card, then buy a small amount such as $5 or $10.

  3. Set a monthly budget under Limits, so it can never cost more than you expect.

  4. Open API keys, press Create new secret key, name it FamilyDB, and copy it. It starts with sk- and is shown only once, so paste it below straight away.

These sites change their look now and then; the links go straight to the right place even when it looks a little different.

It is checked with OpenAI before it is kept, which costs nothing. It is stored on your server and never shown on this page again.

OpenAI’s models, cheapest first: gpt-6-luna (everyday, $0.40 / $1.60); gpt-6 (better, $2.50 / $10); gpt-6-pro (best, $15 / $60). Everyday answers unless you choose a stronger one for the chat, the weekend digest or the lookups, under How strong a model answers on the AI model settings page. Prices are US dollars for a million tokens read and written.

The daily limit US$1.00

What FamilyDB may spend in a day across every message and lookup, as it estimates it. Once reached, it stops asking the AI until midnight and says so. 0 means no limit.

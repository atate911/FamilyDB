Who answers

The model that reads each message and writes the answer comes from one of three companies, and you pay the company for what it uses.

OpenAIrecommendedThe least expensive by far for what FamilyDB does, so it is the one it starts with.answers nowAnthropicClaude. Several times dearer a message with the model it starts on.GoogleGemini, from Google. In between on price.

It is checked with OpenAI before it is kept, which costs nothing. OpenAI answers now, with gpt-6-luna.

How to get a key from OpenAI

  1. Open OpenAI’s developer platform and sign in, or make an account. It is separate from a ChatGPT subscription, which does not include this.

  2. Add some credit under Billing: add a card, then buy a small amount such as $5 or $10.

  3. Set a monthly budget under Limits, so it can never cost more than you expect.

  4. Open API keys, press Create new secret key, name it FamilyDB, and copy it. It starts with sk- and is shown only once, so paste it below straight away.

These sites change their look now and then; the links go straight to the right place even when it looks a little different.

Keeping up with the companies

Once a day it asks each company you have a key for which models the key can use, and reads two public price lists, LiteLLM’s and OpenRouter’s, taking a price when they agree. New models then appear here and new prices are counted, and admins are told on Telegram when a model you use is going or its price moves. No model call, and nothing about the family is sent.

Asking a stronger model to weigh a change

Some changes need judgement rather than a rule: which model should take the place of one that is going, what a refusal nobody can read means, which new models belong at which level, and what a price the lists disagree on really is. With this on, the questions that come up are asked together once a day, with the evening’s lookups, in one call; only a refusal is asked at once. The answer is checked, told to admins, and never changes a setting by itself. It is sent model names, prices and error messages, never the family’s messages.

A few cents each time, and nothing on a day with no question.

Best by default: rare questions, where a better answer is worth a cent more.

A better model at the same cost or less can be put in by itself, and admins are told, with a way to put it back; anything dearer waits for an admin.

Voice notes

Voice notes sent on Telegram are written down by a speech model, then answered as if they had been typed. Claude cannot hear them, so they need an OpenAI or Gemini key.

Off asks the family to type instead.

A longer one is not heard at all, since every minute is paid for. Between 1 and 30.

Leave it alone to use the chat company when it can, else another with a key.

Leave it empty to use Gemini’s lookup model.

Photos

A photo sent on Telegram (a poster, a menu, a ticket) is read by the model that looks things up, which writes down what it shows; that is answered as if it had been typed. The photo goes to that company, costs about a tenth of a cent, and is not kept.

Off asks for it in words. In a group, a photo is looked at only when it is sent to the bot, by a mention in its caption or a reply.

An empty box uses the default it shows.

Where this page is served

Opened at
192.168.1.20, on port 443
FamilyDB listens on
127.0.0.1:8000, and the page is passed on to it by Caddy.

Ports are moved on the server rather than here, so nobody signed in to the page can move it or open it wider. As whoever looks after the server:

  • sudo /opt/familydb/scripts/maintain.sh https --port random serves the page on a port the scans that sweep the internet rarely try, instead of 443; a number chooses it, and --port 443 moves it back. Bookmarks to the old address stop working.
  • sudo /opt/familydb/scripts/maintain.sh port 9090 moves FamilyDB itself off 8000, when something else on the server needs that port: any free one from 1025 to 65535, or random. The address people open stays as it is.

A name for the page

This page is reached by its address, 192.168.1.20. A name, such as family.example.com, is easier to remember and gets rid of the certificate warning for good.

  1. Get the name.

    Any registrar sells one, usually for $10 to $20 a year, or use a part of one you already have, such as family.yourname.com.

  2. Point it here.

    Where the name was bought, add an A record for family.example.com pointing at this network’s address on the internet (your router’s; 192.168.1.20 is only this server’s address at home), and have the router pass ports 80 and 443 on to this server.

  3. Wait for it to take.

    On the server, dig +short family.example.com prints that address once it has: usually minutes, sometimes an hour.

  4. Switch to it.

    On the server, as whoever looks after it:

    sudo /opt/familydb/scripts/maintain.sh https family.example.com

    That gets the certificate and restarts FamilyDB to match. The page is then at https://family.example.com/, and the old address finds nothing, so open the new one and keep it on phones’ home screens again.

    Installed with Docker

    In the .env file beside docker-compose.yml, set these, then run docker compose up -d, which starts Caddy for the certificate:

    WEB_DOMAIN=family.example.com
WEB_TRUST_PROXY=true
COMPOSE_PROFILES=tls

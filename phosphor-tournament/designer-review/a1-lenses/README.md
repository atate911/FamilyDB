# Kitchen Table (green): thirteen lenses

After the owner chose Kitchen Table (green), thirteen fresh reviewers each looked at it alone through one lens (generalist, visual style, design system, interaction, typography, usability, skeptic, parent, kid, accessibility, copy, front-end engineer, phone). Each folder holds its `BRIEF.md` and `review.md`. `SYNTHESIS.md` merges them and records the decisions taken; `FINAL-BRIEF.md` is what A1's designer was given to make it final.
